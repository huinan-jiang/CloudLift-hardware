# ESP32-S3 + 单块 TB6612 + 单电机通电测试

该程序不使用按钮、应变片、限位或蓝牙。通电三秒后自动运行：正转5秒、停止2秒、反转5秒、停止5秒，然后循环。

## 接线

- ESP32-S3 GPIO4 → TB6612 AIN1
- ESP32-S3 GPIO5 → TB6612 AIN2
- ESP32-S3 GPIO6 → TB6612 PWMA
- TB6612 AO1、AO2 → 一个 N20 电机的两根线
- TB6612 VCC → ESP32-S3 3.3V
- TB6612 STBY → ESP32-S3 3.3V
- TB6612 VM → 独立3.0V电机电源正极
- TB6612 GND、ESP32-S3 GND、独立3V电源负极 → 全部共地

`STBY` 已直接接3.3V时，不要再连接GPIO17。

第一次测试应断开机械负载或架空电机。程序烧录完成后，电机电源一接通便会按上述周期运行。

如果电机不启动，在确认接线和电源电流能力后，可以把 `TEST_PWM` 从160提高到200。不要提高超过N20额定3V的供电电压。
