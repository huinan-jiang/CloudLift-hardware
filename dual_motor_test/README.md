# ESP32-S3 双电机异步测试 v0.2.3

## 电机角色

- 位移电机：GPIO4 → AIN1，GPIO5 → AIN2，GPIO6 → PWMA。
- 按摩电机：GPIO40 → PWMC，GPIO41 → CIN2，GPIO42 → CIN1。

两台电机采用独立非阻塞控制：

- 位移电机先用255占空比启动250ms，再以200运行；正转1秒、停止600ms、反转1秒，再停止600ms并循环。
- 按摩电机延迟500ms启动，随后持续单向旋转，不受位移电机暂停和换向影响。
- 通电3秒后自动启动，运行60秒后两台电机自动停止；重新上电可再次测试。

程序使用 `millis()` 状态机控制动作，没有用长时间 `delay()` 阻塞另一台电机。循环末尾的 `delay(2)` 仅给系统任务让出CPU时间。

## 供电

- 驱动板逻辑电源接ESP32-S3的3.3V。
- 电机使用独立稳定3.0V电源。
- ESP32、驱动板和3V电机电源全部共地。
- STBY若直接接3.3V，不再连接任何GPIO。

当前版本没有限位、压力和堵转保护，只能架空测试，不能用于人体。

## 参数调整

- `MOVE_START_PWM`：位移电机起转瞬间功率。
- `MOVE_HOLD_PWM`：位移电机起转后的运行功率。
- `MASSAGE_TARGET_PWM`：按摩电机速度。
- `MASSAGE_DIRECTION`：按摩方向，方向错误时由 `+1` 改成 `-1`。
- `MOVE_RUN_MS`：位移电机单方向运行时间。
- `REVERSAL_PAUSE_MS`：位移换向前停止时间。
- `MAX_TEST_RUN_MS`：一次测试最长时间。
