# CloudLift 四电机空载试转程序

该程序只用于确认 ESP32、两块 TB6612 和四台 N20 电机能够正常运行，不读取压力传感器，也不用于人体测试。

## 运行方式

1. 电机与人体完全分离，最好先卸下会产生夹持的机械负载。
2. TB6612 的 `VCC` 接 ESP32 3.3V，`VM` 接稳定的 3.0V 电机电源，所有模块共地。
3. 按正式接线表连接两块 TB6612。
4. 按钮接在 GPIO32 与 GND 之间；如果没有按钮，也可打开 115200 波特率串口，发送 `r` 启动、发送 `s` 停止。
5. 按一次按钮后四台电机缓启动，弧形电机每 4 秒反向，30 秒后自动停止。运行中再按一次会立即停止。

## 接线

- 左弧形电机：IN1=16，IN2=17，PWM=25
- 右弧形电机：IN1=18，IN2=19，PWM=26
- 左摩擦轮电机：IN1=21，IN2=22，PWM=27
- 右摩擦轮电机：IN1=23，IN2=5，PWM=14
- 两块 TB6612 的 STBY：GPIO13
- 启停按钮：GPIO32

## 方向调整

如果某台电机方向相反，在 `src/main.cpp` 中把对应的 `*_SIGN` 从 `+1` 改成 `-1`，或反向修改。

初始 PWM 为 160/255。若电机不能可靠启动，先确认 3.0V 电源电流能力和接线，再小幅提高 `TARGET_PWM`；不要通过提高电机电压解决。

## 安全限制

- 本测试程序没有压力、限位、堵转或温度保护。
- 不得安装到人体上测试。
- 机械结构装配后，优先改为一次只测一台电机，避免错误方向造成机构碰撞。
- 必须能够立即切断 3.0V 电机电源。
