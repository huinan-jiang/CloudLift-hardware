# 拨云手 ESP32 四电机控制固件

## 硬件

- ESP32 DevKit V1
- TB6612FNG 双路电机驱动板 × 2
- N20 直流减速电机 × 4
- 常闭限位开关 × 2
- 带 0–3.3V 模拟输出的压力/应变放大模块 × 2
- 启停按钮 × 1

两块 TB6612 的 `STBY` 可共接 GPIO13。ESP32、两块驱动板和电机电源必须共地。TB6612 的逻辑电源 `VCC` 接 3.3V，电机电源 `VM` 按 N20 额定电压接入，禁止从 ESP32 的 3.3V 引脚给电机供电。

## 引脚表

| 功能 | ESP32 引脚 |
|---|---:|
| 左弧形电机 IN1 / IN2 / PWM | 16 / 17 / 25 |
| 右弧形电机 IN1 / IN2 / PWM | 18 / 19 / 26 |
| 左摩擦轮 IN1 / IN2 / PWM | 21 / 22 / 27 |
| 右摩擦轮 IN1 / IN2 / PWM | 23 / 5 / 14 |
| 两块 TB6612 STBY | 13 |
| 左 / 右限位 | 34 / 35 |
| 左 / 右压力模拟量 | 36 / 39 |
| 启停按钮 | 32 |

GPIO34、35 没有内部上拉，各加一个 10kΩ 上拉电阻到 3.3V；常闭限位开关接 GPIO 与 GND 之间。正常时读低电平，触发或断线时读高电平。

## 首次调试（不要接触人体）

1. 架空机械结构，断开摩擦轮与皮肤接触。
2. 分别确认四台电机方向；方向相反时修改 `include/config.h` 中对应的 `*_SIGN`。
3. 查看串口中的两路压力原始值，校准零载、目标压力和绝对上限。
4. 手动触发两个限位开关，确认机构只会向离开限位的方向运行。
5. 完成堵转电流测试、过流保护和急停测试后，才能低速带载测试。

## 编译与烧录

使用 VS Code + PlatformIO 打开 `firmware` 目录，连接 ESP32 后执行 Upload；串口监视器波特率为 115200。

## APP 蓝牙通信

固件广播名称为 `CloudLift`，接收 APP 的 JSON 命令并每 500ms 上报状态。完整 UUID、命令和状态定义见项目根目录的 `BLE_PROTOCOL.md`。蓝牙意外断开时，固件会停止按摩并进入安全释放状态。

## 重要限制

当前压力输入按模拟放大模块实现。如果应变片使用 HX711，需要更换为 HX711 数字采集代码。TB6612 每通道的实际承载能力必须大于所选 N20 的堵转电流，否则应更换驱动器。人体接触设备还应增加独立硬件急停、保险丝/限流和温度保护，不能只依赖软件。
