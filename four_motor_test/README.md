# ESP32-S3 四电机异步与应变监测 v0.4.0

## 接线

- 位移电机1：GPIO4 → AIN1，GPIO5 → AIN2，GPIO6 → PWMA。
- 按摩电机1：GPIO40 → PWMC，GPIO41 → CIN2，GPIO42 → CIN1。
- 位移电机2：GPIO45 → PWMD，GPIO48 → DIN2，GPIO47 → DIN1。
- 按摩电机2：GPIO9 → PWMB，GPIO10 → BIN2，GPIO11 → BIN1。
- 应变模块：AO → GPIO14，GND必须与ESP32共地。

应变模块AO电压必须处于0～3.3V。模块若使用5V供电且AO可能超过3.3V，必须加分压或电平转换，禁止直接接入ESP32-S3。

## 动作

- 两台位移电机作为一组同步控制，默认使用相反电气方向以适配左右镜像安装。
- 位移组以255启动250ms，随后降为200；移动1秒、停止600ms、反向移动1秒并循环。
- C通道按摩电机持续旋转，目标PWM为160。
- B通道按摩电机额外延迟300ms，以255启动250ms后降到210持续运行。
- 按摩组与B通道分级启动，减少四台电机同时启动的电流冲击。
- 通电3秒后自动启动，60秒后全部停止；按ESP32的RESET/EN可重新测试。

## 方向调整

如果某台电机物理方向错误，只修改代码顶部对应符号：

- `MOVE1_SIGN`
- `MOVE2_SIGN`
- `MASSAGE1_SIGN`
- `MASSAGE2_SIGN`

在 `+1` 与 `-1` 之间切换。不要为了调整方向而交换多组GPIO定义。

## 安全限制

当前代码没有限位、压力和堵转保护，只能架空或短行程测试。GPIO45是ESP32-S3启动配置相关引脚之一；如果出现无法启动或烧录异常，应优先将PWMD改接其他普通输出GPIO后同步修改代码。

## 应变数据

GPIO14每20ms采样一次，串口监视器使用115200波特率，每200ms输出：

```text
strain raw=1234 filtered=1228 min=1180 max=1305
```

- `raw`：当前12位ADC原始值，范围0～4095。
- `filtered`：一阶低通滤波值。
- `min/max`：本次上电后的最小值和最大值。

v0.4.0仅监测应变数据，不使用该数值控制电机。先记录无载、轻压和较大压力的读数范围，再确定阈值。
